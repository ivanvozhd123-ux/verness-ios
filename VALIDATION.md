# Проверки iOS-проекта

Дата: 9 ноября 2026. Версия исходников: 0.1.2. Хост: Windows.

## Выполнено

- Создан самостоятельный `verness.xcodeproj`: app, Island widget extension,
  unit-test target, зависимости targets, embedding extension и shared scheme.
- OpenStep-парсер прочитал project.pbxproj; проверены ссылки на файлы, ID объектов,
  plist приложения/расширения, scheme XML и ресурсы asset catalogs.
- AppIcon: 1024×1024 PNG, RGB без альфа-канала; исходный клевер verness.
- Tree-sitter Swift разобрал все Swift-файлы без синтаксических ошибок.
  Это проверка грамматики, **не** типизация Apple SDK и **не** компиляция.
- Python-сервер: 6 unittest-проверок прошли. Проверены Bearer-аутентификация,
  маршруты, параметры пагинации, ограничения ID/хостов, opaque stream route,
  передача HTTP Range и подбор Lyrics по метаданным/длительности.
- Реальная сетевая проверка: yt-dlp 2026.10.26 нашёл 20 результатов,
  resolve подготовил M4A; HTTP-прокси отдал корректный аудиодиапазон с MP4 ftyp.
  Тест использовал случайный ключ в памяти; ключи не включены в проект/логи.
- После изменения поиска исполняемого файла повторно подтверждён запуск
  bundled yt-dlp из Windows-проекта.

## Не выполнено

В окружении нет macOS, Xcode и iOS SDK. Поэтому не выполнялись:

- `xcodebuild`, проверка Swift типов относительно Apple SDK, XCTest;
- запуск SwiftUI в iPhone Simulator или на настоящем устройстве;
- проверка воспроизведения через AVAudioEngine, частотной характеристики EQ,
  лимитера, скорости, качества звука и работы без пауз между треками;
- фоновые URLSession-события после завершения процесса;
- поведение ActivityKit/AudioPlaybackIntent/Dynamic Island;
- аудиопрерывания, AirPlay, Bluetooth, энергопотребление и длительная работа в фоне;
- Docker-сборка сервера, подпись и экспорт IPA.

Нативные XCTest добавлены для LRC, правил очереди/повтора, Codable-библиотеки,
защиты путей и политики HTTPS, но **здесь не запускались**.

Первый обязательный шаг на Mac: `bash scripts/build.sh`, затем
`bash scripts/test.sh`. Результаты этой проверки не заменяют запуск в Xcode.
